# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: open the repository's **Security** tab
and choose **Report a vulnerability** (GitHub private security advisories). Do not open a public
issue or post details on Discord.

Include the ClipCheck version, Windows version, steps to reproduce and the impact you expect. You
will get a reply in the advisory thread; a fix is released before details are made public.

## Supported versions

Only the latest release receives security fixes.
