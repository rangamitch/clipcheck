# ClipCheck 0.5.3

- **Fixed: "Start with Windows".** The setting is now applied. ClipCheck adds itself to Windows startup when you turn it on and removes itself when you turn it off, and it shows in Task Manager's Startup tab.
- **Fixed: no microphone in Discord embeds.** Clips and trims now write the Mix audio track first, so players that only play the first audio track (such as Discord's embed) include your microphone. Windows Photos may now open on a different audio track by default; use its audio track menu to switch.
- **Fixed: gallery badges drawing over the toolbar.** The Clip and Session badges no longer appear in front of the search box and filters when you scroll.
- **New: Logs & diagnostics.** A button at the bottom of the Settings menu opens the logs folder, copies a diagnostics report (versions, system info and the recent log, with your Windows user name hidden) or saves it as a text file in Downloads, for bug reports.
