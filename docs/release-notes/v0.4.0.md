# ClipCheck 0.4.0

- **Experimental Capture** (Video tab → Capture Method): an opt-in Desktop Duplication source for Windows 10 that avoids the yellow capture border.
- Gallery multi-select: Select all, bulk delete, and drag a rubber band to select several clips at once.
- mp4 files now write the Mix audio track last, so Windows and Photos play it by default.
- Text selection is disabled app-wide (inputs excepted).
- Fixes: shutdown drain timeout, Video tab failing to load, hotkey hook Alt handling on injected input, and a session attach race.
