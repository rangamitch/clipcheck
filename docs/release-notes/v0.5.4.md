# ClipCheck 0.5.4

- **Fixed: games not detected next to an overlay.** A click-through overlay (such as a crosshair) could take the place of the game, so a game like FiveM was never picked up and recording stayed on "Waiting For Game". Overlay windows are now ignored by detection.
- **Fixed: a game could not be added by hand.** In Settings > Games, the "Add a game" list greyed out any game ClipCheck knew about as "Already detected automatically", even when detection had not actually started it. It now only says that when detection really accepted the game, so you can add it yourself.
- **Fixed: cache growth.** Old audio sidecar files no longer pile up, the player cache is capped, and Settings has a new "Clear cache" button.
- **Fixed: leftover crash data.** Stage folders from crashed sessions are deleted after 7 days instead of being kept forever.
- **Fixed: microphone lane in the editor.** The editor now places a single microphone lane, following the push-to-talk mix setting.
