# ClipCheck 0.4.1

- **Push to talk** (Settings → Hotkeys): bind up to 4 push-to-talk keys, using keyboard keys or mouse buttons (middle, back, forward). Your mic only records while any of them is held, with an adjustable release delay (default 250 ms) so the end of a sentence isn't clipped.
- **Push to talk on its own track** (Settings → Audio, optional): record push to talk on a separate "Push to talk" track while "Microphone" keeps recording your open mic, and choose whether the Mix track carries push to talk or the open mic. "Push to talk only" records no open mic at all.
- The mute hotkey now works as a plain toggle.
- Fixes: the mic test recording can play back again, and the update dialog shows release notes as formatted text.
