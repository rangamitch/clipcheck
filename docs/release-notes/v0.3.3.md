# ClipCheck 0.3.3

- Update dialog: after a recording blocks the update you can now choose **Stop recording and update** (the recording is saved first), or stop it yourself and use **Try again**. The old "recording in progress" message no longer sticks after the recording has ended.
- A found update is remembered, so the update pill is back after you restart ClipCheck.
- Update pill now reads "New Update Available". Settings → Updates gets an **Update to X** button next to **Check now**, and Check now opens the update prompt when it finds a newer version.
