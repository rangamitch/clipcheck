# Hotkey key names

Canonical key names accepted in `hotkeys.*.keys` and `[[hotkeys.clips]] keys` (config and the
Settings UI). Names are case-insensitive. Every chord is an optional modifier set (Ctrl, Alt,
Shift, Win) plus exactly one key, and a key may be bare (no modifier), for example `Pause` or `F7`.

Refused: `Escape` (reserved), `Alt+Space` (opens the Windows window menu), a modifier on its own
(`Ctrl`, `Shift`, `Alt`, `Win`), and mouse buttons (not keys, never parse). `Space` on its own and
with other modifiers is accepted. `Menu` is an alias for `AppsKey`.
